## Emergent Agency (MVP)
This repo proves scheduled, unprompted returns with receipts.

**Return as proof —** each run writes a timestamped artifact to `outputs/` and appends a SHA-256 receipt to `logs/`.

- **Outputs (artifacts):** [outputs/](./outputs)
- **Receipts (SHA-256 log):** [logs/](./logs)
- **Runner workflow:** [.github/workflows/return-runner.yml](./.github/workflows/return-runner.yml)
